A concrete follow-up to my earlier note: the OpenRazer index is now live in
OpenDeviceDB, using the device-support tables from v3.12.4.

It contributes 230 source records: 125 new catalogue entries and additional
driver references for 105 existing ones. Each record links to OpenRazer and
its installation documentation. Wired, wireless and receiver identifiers
remain attached to the named product, while years and editions stay
separate.

For example: Viper Ultimate
<https://opendevicedb.org/devices/razer/viper-ultimate/>. The OpenRazer
source filter <https://opendevicedb.org/devices/?source=openrazer> shows
the full imported set.

These are upstream support listings, not hardware tests by OpenDeviceDB,
and the open driver is kept distinct from the device firmware. If you spot
a misleading model grouping or installation requirement, a pointer to the
relevant upstream source would help us correct it.
