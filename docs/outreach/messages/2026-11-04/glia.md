<p>Hello Glia team,</p>
<p>I came across your open medical hardware work and the international community helping document, develop and manufacture it.</p>
<p>After <a href="https://github.com/morluto/rea">REA</a> was released, I created <a href="https://opendevicedb.org">OpenDeviceDB</a>, an open directory that links device models and identifiers to available protocols, firmware, software and source documentation, so that people can find and reuse existing work. The code is AGPL-3.0 and the data is CC BY-SA 4.0.</p>
<p>A recent example is my documentation of <a href="https://github.com/opendevicedb/opendevicedb/blob/main/data/devices/bmv/ul10-5e.yaml">a BMV USB ultrasound probe</a>: the record distinguishes observed identity reads from partially mapped protocol details; image acquisition remains unverified.</p>
<p>Would structured records linking specific devices to their source designs, documentation and development status be useful to Glia contributors? I would be happy to discuss a small example and learn which details would make it useful for people trying to reproduce or maintain hardware.</p>
