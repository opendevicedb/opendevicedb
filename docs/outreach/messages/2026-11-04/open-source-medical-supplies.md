<p>Hello Open Source Medical Supplies team,</p>
<p>Your design library and work connecting local fabrication communities caught my attention. I am interested in helping people find and reuse technical knowledge that is currently spread across many projects.</p>
<p>After <a href="https://github.com/morluto/rea">REA</a> was released, I created <a href="https://opendevicedb.org">OpenDeviceDB</a>, an open directory that links device models and identifiers to available protocols, firmware, software and source documentation, so that people can find and reuse existing work. The code is AGPL-3.0 and the data is CC BY-SA 4.0.</p>
<p>A recent example is my documentation of <a href="https://github.com/opendevicedb/opendevicedb/blob/main/data/devices/bmv/ul10-5e.yaml">a BMV USB ultrasound probe</a>: the record distinguishes observed identity reads from partially mapped protocol details; image acquisition remains unverified.</p>
<p>Would there be value in linking relevant entries in your design library to device records in OpenDeviceDB? I would welcome your feedback and suggestions for a few suitable examples, as well as the appropriate place to introduce the project to your community.</p>
<p>Best regards,<br>Sébastien Michea<br><a href="https://github.com/opendevicedb/opendevicedb">github.com/opendevicedb/opendevicedb</a></p>
