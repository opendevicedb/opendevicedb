I'm Sebastien, creator of [OpenDeviceDB](https://opendevicedb.org/), an independent [open-source catalogue](https://github.com/opendevicedb/opendevicedb) linking device models to firmware, drivers and tools. I would like board lookups to point users to TinyGo's official documentation.
The [Pico W guide](https://tinygo.org/docs/reference/microcontrollers/featured/pico-w/) shows why exact variants matter: its LED needs different handling from Pico. Entries would retain target, compiler release, installation links and feature limits. I'd welcome feedback on this approach. No TinyGo importer, board record, compiler build or hardware test is implemented by this proposal.
