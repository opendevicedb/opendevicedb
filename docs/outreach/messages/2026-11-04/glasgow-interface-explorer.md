Hi everyone,

I created [OpenDeviceDB](https://opendevicedb.org) after the release of REA: an open directory linking device models to existing protocol documentation, drivers and open firmware. The aim is to make earlier work easier to find before someone repeats an investigation. It is my project.

Glasgow users working with UART, SPI or JTAG seem a particularly relevant audience. A useful directory contribution can be small: the exact board revision plus a link to an existing pinout, protocol write-up or working tool, with the limits of the observation stated. Complete device support is not required.

There is no Glasgow integration or applet import at present. I’m sharing the directory as a possible place to discover and link existing results; this post contains no proposed change to Glasgow.

Would this help with any of your investigations? If you have one public device write-up that is hard to find by model name, I can prepare an OpenDeviceDB entry linking back to it. Feedback on what would make such an entry useful is welcome too.
