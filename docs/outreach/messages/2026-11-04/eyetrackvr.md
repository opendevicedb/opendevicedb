I'm Sebastien, the creator of [OpenDeviceDB](https://opendevicedb.org/), an independent open-source directory linking physical device models to firmware, drivers, tools and protocol research. [Project source](https://github.com/opendevicedb/opendevicedb).

I would maintain the catalogue links on my side. Your software's Babble license would remain identified separately from documentation and hardware licenses; this proposal is about linking to the original projects.

Are there particular board/camera or firmware combinations that a downstream directory should distinguish first? I'd welcome feedback on a small, useful starting point. No EyeTrackVR importer, new catalogue record or hardware test has been completed for this proposal.
