Hello Open-Source Leg community,

I created [OpenDeviceDB](https://opendevicedb.org) following the release of REA. It is my open-source directory linking device models to existing drivers, protocol documentation and open firmware, so people can find earlier work before starting another implementation.

Your SDK looks relevant well beyond the leg platform: someone looking for an AS5048B encoder interface, for example, could discover your implementation and its documentation through the device entry. I also noticed that your hardware table distinguishes unit tests, hardware tests and benchmarks. Those are useful distinctions to preserve when describing what an interface supports.

OpenDeviceDB does not currently import opensourceleg. I would be interested in starting with one entry linking an exact component model to its SDK driver and documentation, with the SDK version and any relevant hardware or firmware constraints. I can prepare that entry on the directory side for correction, keeping attribution and links to your project.

Would this be useful to your community? A suggestion for the first component, or one compatibility detail a downstream directory should retain, would help. I would also welcome feedback from anyone who tries searching for hardware they already use.
