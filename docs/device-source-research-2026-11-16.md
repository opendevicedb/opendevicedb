# Device-source research — 2026-11-16

## Import implementation update

All five candidates below now have registered importers and validated snapshots: **117 Meshtastic**, **438 Armbian**, **639 CircuitPython**, **116 Ubuntu Touch** and **37 Droidian** records. The merged catalogue contains **32,130 unique devices across 42 imported sources**, adding 1,190 devices and enriching 129 pre-existing records. These are catalogue identities, not hardware-test results or a count of working Linux phones.

Implementation resolved two questions from the initial research: CircuitPython uses the explicitly licensed **10.3.2 firmware board definitions**, excluding Blinka hosts and the Renode emulator; Ubuntu Touch's published website footer declares **CC-BY-SA-4.0**, while installer configurations retain GPL-3.0. Droidian's metadata licence remains unspecified: only an original factual model/status index is published, with original summaries and links, without copying upstream prose, installation instructions, images or credits. Potential ports remain unknown, with no installation route. No licence for that upstream dataset is invented.

The following sections preserve the **initial research**, whose upstream entry counts differ from the final deduplicated imports. The Alcatel investigation remains unresolved; these imports establish no 5033XR Linux port.

## Alcatel 1 (2021), exact model 5033XR

**Finding: no ready-to-install mobile Linux port for this exact model was found in the checked sources.** This is a bounded research result, not proof that no unpublished or unindexed work exists.

The [manufacturer's 5033XR manual](https://www.alcatelmobile.com/wp-content/uploads/2021/11/Alcatel-1_5033XR_UM_EN_V0.3_20210929.pdf) identifies the exact model and specifies MT6739, Android R Go, 1 GB RAM and 16 GB storage. `Macau` is the codename supplied in [request 47](https://github.com/opendevicedb/opendevicedb/issues/47). A shared codename or chipset alone does not establish cross-variant compatibility.

Checked evidence:

- **Nura/postmarketOS:** enumerated every direct entry, following API pagination, under all five `device/` categories at pmaports revision [`ce3ebdba08cdd09a6fb9a01da7d750f05638a25e`](https://gitlab.postmarketos.org/postmarketOS/pmaports/-/tree/ce3ebdba08cdd09a6fb9a01da7d750f05638a25e/device). Category entry counts: main 3, community 105, testing 341, downstream 40, archived 991; these include kernel/firmware packages, not just devices. No path matched `macau`, `5033` or `mt6739`. The Alcatel-named paths found were archived ports for other products, including Idol 3, 5010D, Pop 7 LTE and Telekom Puls. The wiki returned an access-denied page, so this conclusion uses the current repository inventory, not a successful wiki search.
- **Ubuntu Touch:** no Alcatel listing in the official 111-entry device page and no `alcatel`, `macau` or `5033` path in the pinned installer-config tree above.
- **Droidian:** no Macau entry among the 33 imported device JSONs or their filenames at the inspected revision. Its [porting guide](https://github.com/droidian/porting-guide) explains the Android/Halium adaptation work; meeting a general Android-version prerequisite is not a working port.
- **Mobile NixOS:** no Alcatel in its [published device list](https://mobile.nixos.org/devices/). Devices in that list have explicitly differing support levels.
- Targeted web and public GitHub code searches for `5033XR` with Linux, postmarketOS, Ubuntu Touch and Droidian did not produce an exact-model port. Some results were ordinary Android browser user-agent strings containing the word Linux; these are not evidence of a replacement OS. Search results are not exhaustive.

### Concrete development leads

1. **Macau kernel source:** [`mt6739/android_kernel_alcatel_macau`](https://github.com/mt6739/android_kernel_alcatel_macau/tree/7828cecf9f8c9a82b11f2b72986b272208d616b8), branch `tweaks`. The [Makefile](https://github.com/mt6739/android_kernel_alcatel_macau/blob/7828cecf9f8c9a82b11f2b72986b272208d616b8/Makefile) declares **4.14.186**. There are `macau_defconfig` and `macau_1g_defconfig` variants; the latter declares `CONFIG_MTK_PLATFORM="mt6739"` and `CONFIG_ARCH_MTK_PROJECT="macau_1g"`. This is an Android kernel tree, not a completed mainline mobile-Linux port. No GitHub releases were returned. Source review only; no build or boot test.
2. **TWRP device tree:** [`mt6739/twrp_device_alcatel_macau`](https://github.com/mt6739/twrp_device_alcatel_macau/tree/30412368cc42b4488f137828cd1a5ae547418f54) explicitly describes itself as **WIP for Alcatel 1 (2021) 5033F**. Its BoardConfig uses a prebuilt kernel and ARMv7 userspace settings. It does not establish a working recovery for 5033XR and is not a Linux phone distribution. No GitHub releases were returned.
3. **Alcatel Mobile source publication:** [`OT_5033_20210804.tar.xz`](https://sourceforge.net/projects/alcatel/files/OT_5033_20210804.tar.xz/) is listed as a 114.8 MB source archive dated August 4, 2021. The [download page](https://sourceforge.net/projects/alcatel/files/OT_5033_20210804.tar.xz/download) publishes SHA-256 `4499e2d9053f83a20f519ff31c433a9a7b4a18ad87537879a0e3254913e72640`. Two bounded download attempts timed out, leaving an incomplete local file: contents and checksum were not verified, and correspondence to the exact XR build is unresolved. Do not present it as an installable image or an inspected XR kernel package.

The useful next investigation is to establish the XR's exact build, board configuration, kernel and documented bootloader state, then compare them with the 5033F/Macau sources. A kernel source tree, a recovery project or generic MediaTek tooling alone does not establish display, touch, storage, modem, audio or suspend support. No firmware was flashed, no device connected, no exact-model install route added, and request 47 remains unresolved.
